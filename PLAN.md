# PARTICLE GOD
1. Render one continuous warm-white field with stable particle identities.
2. Sample an original stylized bust, spiral galaxy and extruded canvas-letter surfaces.
3. Store position/velocity in GPU ping-pong textures; spring, pointer, turbulence and damping remain independent forces.
4. Start at 65,536 particles; expose 16,384 / 65,536 / 589,824 quality budgets and adapt down under sustained load.
5. Fall back to 8,192 CPU particles when floating-point simulation is unavailable.
6. Keep chapter state, target sampling and numerical rules separate from the render adapter.
7. Complete void → face → galaxy → custom word → replay before polish.
8. Keep gestures local so the face repairs behind a dragged pointer.
9. Handle mobile, keyboard, gentle mode, resize and context restoration.
10. Test deterministic sampling, bounds, damping and state progression; build/typecheck.
11. Parent performs sequential browser and visual QA before publication.
